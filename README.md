Bahia Heat — a 3D open-world crime game set in Bahia, a sun-soaked coastal city at sunset. Explore the city on foot and by car, steal and drive five original car models, dodge traffic and pedestrians, run six story jobs with voiced-style dialog and character portraits, and lose the Bahia PD — pursuit cars, roadblocks and a searchlight helicopter — while the wanted stars climb. Full HUD: speed, wanted level, minimap, police response panel, mission tracker, radio, cash and REP.

## Run it
```sh
node serve.ts
```
Then open http://localhost:8080. No network needed — everything is vendored locally, including three.js.
